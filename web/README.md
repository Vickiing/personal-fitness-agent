# Personal Fitness Agent — Web

Espaço reservado para a versão web do aplicativo, com hospedagem futura no Azure.

A implementação web deve reutilizar os contratos e regras determinísticas de `mobile/src/PersonalFitnessAgent.Core` sem depender da interface MAUI. O projeto ainda não define autenticação, persistência remota, sincronização nem serviços Azure. Esses pontos precisam de requisitos e decisões explícitas antes de adicionar chamadas de nuvem ou armazenar dados de saúde remotamente.

A experiência mobile permanece offline-first e independente desta versão web.
